# BlueCoder MVP product brief

**Audience:** software developers who want control over architecture and implementation without repeatedly writing long prompts.

**Core journey:** describe objective → inspect repository → recommend architecture/stack → ask high-impact questions → draft execution brief → approve → orchestrate agents → validate → deliver.

**Approval modes:** manual, smart, autopilot (subject to independent tool permissions).

**User preferences:** desired control level (automatic/guided/expert), favorite stacks, coding conventions, risk tolerance, and preferred agents. Avoid inferring seniority from job titles.

**Non-goals for v1:** generic marketing image generation, unbounded autonomous execution, proprietary model hosting, or guaranteed monetary savings on flat-rate subscriptions.

**Success metrics:** task completion, rework, elapsed time, tool calls, verified output quality, and provider usage when available.
